# الدليل البصري لجلسات التحقق (Form Visual Guide)

هذا الدليل يربط كل مهمة في نصوص التحقق باللقطة البصرية المناسبة من مجلد `qa/artifacts/`، لمساعدة الميسر أو المشارك في مقارنة ما يراه على شاشة النموذج الأولي أثناء تعبئة استمارة التحقق (Google Form).

---

## 1. تعليمات التشغيل على الشبكة المحلية (Wi-Fi)

لكي يتمكن أعضاء القسم من فتح النموذج الأولي على أجهزتهم أو هواتفهم عبر نفس شبكة الـ Wi-Fi:

1. شغّل الأمر التالي في مجلد المشروع لبناء وتشغيل الخادم:
   ```bash
   npm run build
   npm run start:lan
   ```
2. استخرج عنوان IP الخاص بجهازك في الشبكة المحلية عبر PowerShell:
   ```powershell
   (Get-NetIPAddress -AddressFamily IPv4 -InterfaceAlias "Wi-Fi*").IPAddress
   ```
   (أو ابحث عن IPv4 Address في إعدادات الشبكة، مثل `192.168.1.50`).
3. شارك الرابط مع المشاركين:
   ```
   http://<YOUR-IP>:3000
   ```
4. اطلب من المشارك فتح صفحة الحساب واختيار **إعادة النموذج إلى حالته الأولى**، ثم تحديد دوره من قائمة **عرض بصفة** قبل بدء المهام.

## 3. ملاحظات حول قيود النموذج الأولي للميسر والمشاركين

يجب التنويه مسبقاً للمشاركين بأن الأمور التالية هي قيود متعمدة في النموذج الأولي وليست أخطاء برمجية:
1. **عدم وجود رفع فعلي للملفات:** ملفات التصميم والفيديو ممثلة بأصول نموذجية ورسوم توضيحية.
2. **إعادة الضبط عند تحديث الصفحة:** البيانات مخزنة محلياً في الذاكرة المؤقتة للمتصفح، والزر في صفحة الحساب يعيد البيانات لحالتها الابتدائية.
3. **النشر والتكاملات محاكاة برمجية:** لا يتم إرسال منشورات حقيقية إلى منصات التواصل الاجتماعي.
4. **لوحة الإدارة والإعدادات:** واجهات هيكلية تمثيلية لتوضيح المفاهيم والتوزيع الإداري.
