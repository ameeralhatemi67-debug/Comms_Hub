# Who edited (F-R01-19, Severity 2)

**The department's answer.** When the Director edits a writer's text
himself, the system saves the edit and shows who edited, without taking the
original author's credit (R01, S1 structural question 3).

**Conflict.** Partly supported already. The prototype's activity log names
who saved each version («محمد: حُفظ إصدار جديد»), and the assignee stays the
author. What is missing is the editor on the version itself, in the release
history and the version difference of task 0.2.3.8, where a reviewer would
look.

**Options.**
1. Record the editor on every revision and show it next to the version number
   («الإصدار 3 · حرره محمد») while the work keeps its assignee as author.
2. Rely on the activity log. Already present, but not where the question is
   asked.

**Recommendation.** Option 1. Recording belongs to the event and audit
foundation of Checkpoint 1.4; showing it on versions belongs to Checkpoint
2.3. It is small enough to add to the prototype if the owner wants it shown at
the re-check; otherwise defer.
